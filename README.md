# Social Media Platform

A full-stack social media web application built with the MERN stack (MongoDB, Express, React, Node.js).

## Features

- User authentication (Register/Login/Logout) with JWT
- Create, like, comment, and delete posts
- User profiles with bio and profile picture upload
- Real-time post timestamps
- Dark/Light mode toggle

## Tech Stack

**Frontend:** React, React Router, Vite
**Backend:** Node.js, Express.js
**Database:** MongoDB (Mongoose)
**Authentication:** JWT (JSON Web Tokens), bcryptjs
